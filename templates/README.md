# Workspace templates

These files document the versioned surface created by OneCo OS. Prefer the CLI for real workspaces because it assigns stable project IDs, creates independent Git repositories, and initializes local runtime state atomically.

- `company/` contains the company charter, role contracts, and valid example control files.
- `project/` contains the pre-launch project scaffold for an example `PROJ-001`.

Replace example prose during conversational shaping. Do not renumber a registered `PROJ-*` ID or launch an Owner while `TBD` fields or launch endorsements remain unresolved. The company manifest example is v2: Cockpit on native macOS webview, executives in Ghostty, and Owners in hidden tmux.
