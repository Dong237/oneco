## Scope Guard

## Procedure

1. Read the constitution, `BRIEF.md`, active feature state, and dependent templates.
2. Replace every placeholder with concrete, testable governance. Use MUST for non-negotiable rules.
3. Preserve the OneCo principles: vertical delivery, simplicity, evidence, safe boundaries, and
   honest escalation.
4. Apply semantic versioning: MAJOR for incompatible governance, MINOR for material additions,
   PATCH for clarification. Use ISO dates.
5. Synchronize `plan-template`, `spec-template`, and `tasks-template` when a rule changes them.
6. Prepend a Sync Impact Report naming the version change, principle changes, synchronized files,
   and any deferred item.
7. Verify no unexplained placeholder remains and report deferred non-governance input as next actions.
